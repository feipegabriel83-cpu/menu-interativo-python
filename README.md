# Calculadora Interativa em Python

Projeto simples desenvolvido em Python com um menu interativo capaz de:

- Somar números
- Multiplicar valores
- Mostrar o maior número
- Permitir inserir novos números
- Encerrar o programa

## Tecnologias utilizadas
- Python 3

## Conceitos praticados
- while
- if / elif / else
- Operadores matemáticos
- Comparações
- Estruturas de repetição
- Entrada de dados com input()

## Objetivo
Praticar lógica de programação e estruturas de repetição através de um sistema interativo no terminal.
